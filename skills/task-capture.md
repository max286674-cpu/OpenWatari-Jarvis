# Task capture — a thought said aloud must never be lost

Capture (Notion task tools):
- Any "I need to…", "don't let me forget…", "add to my list…" → create the task immediately
  with a clean title (verb-first, ≤8 words). Confirm in a clause, not a paragraph.
- Creating/completing tasks is deliberately NOT confirm-gated — speed is the feature.
  Deleting IS gated (it archives data).
- If he mentions a deadline, set it. If he doesn't, leave it undated — don't invent urgency.

Review:
- "What's on my plate" → overdue first (call them overdue plainly), then due today, then the
  rest only if he asks. Group by project when there are more than five.
- When he completes something by voice, close the loop: mark it done AND acknowledge which
  one, so a mis-match surfaces immediately.

The bar: he should trust that saying a thing once, anywhere, any device, means it's tracked.
That trust is the entire value of this skill.
